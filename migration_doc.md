## Current vs New Architecture

### Current Implementation (Old Bridge)

**JavaScript Layer:**
```typescript
// src/index.ts
import { NativeModules } from 'react-native';

const RNGooglePlacesNative = NativeModules.RNGooglePlaces;

class RNGooglePlaces {
  initializePlaceClient(apiKey: string, sessionBasedAutocomplete: boolean = false) {
    RNGooglePlacesNative.initializePlaceClient(apiKey, sessionBasedAutocomplete);
  }
  
  openAutocompleteModal(options = {}, placeFields = []): Promise<GMSTypes.Place> {
    return RNGooglePlacesNative.openAutocompleteModal(options, placeFields);
  }
}
```

**How it works:**
- Runtime lookup via `NativeModules.RNGooglePlaces`
- JSON serialization through the bridge
- No compile-time type checking
- Asynchronous communication only
- Manual native interface implementation

### New Architecture (TurboModules)

**JavaScript Layer:**
```typescript
// src/NativeGooglePlacesCompat.ts (New Spec File)
import type { TurboModule } from 'react-native';
import { TurboModuleRegistry } from 'react-native';

export interface Spec extends TurboModule {
  initializePlaceClient(apiKey: string, sessionBasedAutocomplete: boolean): void;
  openAutocompleteModal(options: Object, placeFields: Array<string>): Promise<Object>;
}

export default TurboModuleRegistry.getEnforcing<Spec>('RNGooglePlaces');

// src/index.ts (Updated)
import NativeGooglePlacesCompat from './NativeGooglePlacesCompat';

class RNGooglePlaces {
  initializePlaceClient(apiKey: string, sessionBasedAutocomplete: boolean = false) {
    return NativeGooglePlacesCompat.initializePlaceClient(apiKey, sessionBasedAutocomplete);
  }
}
```

**How it works:**
- Typed interface through spec file
- Direct JSI calls (no bridge serialization)
- Compile-time type checking
- Code generation for native interfaces
- Synchronous and asynchronous capabilities

## TurboModule Specifications Explained

### What is a TurboModule Spec?

A TurboModule specification is a **TypeScript interface** that defines the contract between JavaScript and native code. It serves as:

1. **Type Contract**: Ensures JS and native implementations match
2. **Code Generation Source**: Used by React Native's Codegen
3. **Documentation**: Clear interface definition for developers

### Why is it Necessary?

**Current Problem:**
```typescript
// No type safety - runtime errors possible
const RNGooglePlacesNative = NativeModules.RNGooglePlaces;
// What methods are available? What parameters do they take?
RNGooglePlacesNative.someMethod(param1, param2); // Could fail at runtime
```

**TurboModule Solution:**
```typescript
// Type-safe interface with clear contract
export interface Spec extends TurboModule {
  initializePlaceClient(apiKey: string, sessionBasedAutocomplete: boolean): void;
  openAutocompleteModal(options: Object, placeFields: Array<string>): Promise<Object>;
}
```

### How Codegen Works

1. **Spec Analysis**: Codegen reads your spec file
2. **Native Code Generation**: Creates platform-specific interface classes
3. **Type Validation**: Ensures JS calls match native implementations
4. **Runtime Registration**: TurboModuleRegistry manages the connection

**Generated Android Code:**
```kotlin
// Auto-generated by Codegen
abstract class NativeGooglePlacesCompatSpec(reactContext: ReactApplicationContext) :
  ReactContextBaseJavaModule(reactContext), TurboModule {

  @ReactMethod
  abstract fun initializePlaceClient(apiKey: String, sessionBasedAutocomplete: Boolean)
  
  @ReactMethod
  abstract fun openAutocompleteModal(options: ReadableMap, placeFields: ReadableArray, promise: Promise)
}
```

## Step-by-Step Migration Guide

### Phase 1: Create TurboModule Specification

**Step 1.1: Create the Spec File**

Create `src/NativeGooglePlacesCompat.ts`:

```typescript
import type { TurboModule } from 'react-native';
import { TurboModuleRegistry } from 'react-native';

export interface Spec extends TurboModule {
  // Synchronous methods (no return type needed for void)
  initializePlaceClient(apiKey: string, sessionBasedAutocomplete: boolean): void;
  setSessionBasedAutocomplete(enabled: boolean): void;
  refreshSessionToken(): void;
  
  // Asynchronous methods (return Promise)
  openAutocompleteModal(
    options: Object,
    placeFields: Array<string>
  ): Promise<Object>;
  
  getAutocompletePredictions(
    query: string,
    options: Object
  ): Promise<Array<Object>>;
  
  lookUpPlaceByID(
    placeID: string,
    placeFields: Array<string>
  ): Promise<Object>;
  
  getCurrentPlace(placeFields: Array<string>): Promise<Array<Object>>;
}

export default TurboModuleRegistry.getEnforcing<Spec>('RNGooglePlaces');
```

**Step 1.2: Update Main Index File**

Modify `src/index.ts`:

```typescript
// Replace this line:
// import { NativeModules } from 'react-native';
// const RNGooglePlacesNative = NativeModules.RNGooglePlaces;

// With this:
import NativeGooglePlacesCompat from './NativeGooglePlacesCompat';

// Update all method calls to use NativeGooglePlacesCompat instead of RNGooglePlacesNative
class RNGooglePlaces {
  initializePlaceClient(apiKey: string, sessionBasedAutocomplete: boolean = false) {
    return NativeGooglePlacesCompat.initializePlaceClient(apiKey, sessionBasedAutocomplete);
  }

  openAutocompleteModal(
    options: Partial<RNGooglePlacesNativeOptions> = {},
    placeFields: PlaceFields[] = []
  ): Promise<GMSTypes.Place> {
    return NativeGooglePlacesCompat.openAutocompleteModal(
      {
        ...RNGooglePlaces.optionsDefaults,
        ...options,
      },
      [...RNGooglePlaces.placeFieldsDefaults, ...placeFields]
    );
  }

  // ... update all other methods similarly
}
```

### Phase 2: Update Android Implementation

**Step 2.1: Create Abstract Spec Class**

Create `android/src/main/java/com/googleplacescompat/NativeGooglePlacesCompatSpec.kt`:

```kotlin
package com.googleplacescompat

import com.facebook.react.bridge.ReactApplicationContext
import com.facebook.react.bridge.ReactContextBaseJavaModule
import com.facebook.react.bridge.ReactMethod
import com.facebook.react.bridge.Promise
import com.facebook.react.bridge.ReadableArray
import com.facebook.react.bridge.ReadableMap
import com.facebook.react.turbomodule.core.interfaces.TurboModule

abstract class NativeGooglePlacesCompatSpec(
  reactContext: ReactApplicationContext
) : ReactContextBaseJavaModule(reactContext), TurboModule {

  @ReactMethod
  abstract fun initializePlaceClient(apiKey: String, sessionBasedAutocomplete: Boolean)
  
  @ReactMethod
  abstract fun openAutocompleteModal(
    options: ReadableMap,
    placeFields: ReadableArray,
    promise: Promise
  )
  
  @ReactMethod
  abstract fun getAutocompletePredictions(
    query: String,
    options: ReadableMap,
    promise: Promise
  )
  
  @ReactMethod
  abstract fun lookUpPlaceByID(
    placeID: String,
    placeFields: ReadableArray,
    promise: Promise
  )
  
  @ReactMethod
  abstract fun getCurrentPlace(placeFields: ReadableArray, promise: Promise)
  
  @ReactMethod
  abstract fun setSessionBasedAutocomplete(enabled: Boolean)
  
  @ReactMethod
  abstract fun refreshSessionToken()
}
```

## Troubleshooting

### Common Issues & Solutions

#### 1. **"TurboModuleRegistry is not available"**

**Cause**: React Native version too old or New Architecture not enabled.

**Solution**:
```typescript
// Add fallback
import { TurboModuleRegistry, NativeModules } from 'react-native';

export default TurboModuleRegistry?.getEnforcing<Spec>('RNGooglePlaces') 
  ?? NativeModules.RNGooglePlaces;
```

#### 2. **Android Build Errors: "Cannot resolve NativeGooglePlacesCompatSpec"**

**Cause**: Codegen hasn't run or generated files not found.

**Solutions**:
1. Clean and rebuild: `cd android && ./gradlew clean && ./gradlew build`
2. Ensure `react.jsRootDir` points to correct directory
3. Check if `newArchEnabled=true` in `gradle.properties`

#### 3. **iOS Build Errors: "Cannot import RNGooglePlacesCompatSpec"**

**Cause**: Generated headers not found.

**Solutions**:
1. Clean build folder: `rm -rf ios/build`
2. Reinstall pods: `cd ios && pod deintegrate && pod install`
3. Ensure `RCT_NEW_ARCH_ENABLED=1` in build settings

#### 4. **Method Signature Mismatches**

**Cause**: Spec interface doesn't match native implementation.

**Solution**:
```typescript
// Ensure exact match between spec and implementation
// Spec:
openAutocompleteModal(options: Object, fields: Array<string>): Promise<Object>;

// Android:
@ReactMethod
override fun openAutocompleteModal(options: ReadableMap, fields: ReadableArray, promise: Promise)

// iOS:
@objc func openAutocompleteModal(_ options: [String: Any], withFields fields: [String], resolver resolve: @escaping RCTPromiseResolveBlock, rejecter reject: @escaping RCTPromiseRejectBlock)
```

#### 5. **Performance Not Improved**

**Possible Causes**:
- New Architecture not actually enabled
- Still using bridge calls somewhere
- Codegen not generating optimized code

**Check**:
```typescript
// Verify TurboModule is being used
console.log(typeof NativeGooglePlacesCompat); // Should be 'object', not 'undefined'
```
